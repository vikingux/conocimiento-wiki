# Demo de venta

Un sitio de ejemplo hecho con `.lnd`: portada, demos por caso (un estudio de abogados, un equipo de desarrollo, el trámite del RUC en Ecuador), paquetes y contacto. Funciona sin internet.

- **Sin instalar nada:** abre [`sitio/index.html`](sitio/index.html) con doble clic.
- **Con el programa `lndvisor`:** descarga el archivo de tu sistema (`abrir-windows.exe`, `abrir-mac-arm`, `abrir-mac-intel`, `abrir-linux` o `abrir-linux-arm`) o el paquete completo `demo-venta.zip` desde los archivos de la release 0.9.2 en GitHub. Los ejecutables no van dentro del repositorio.
- Las instrucciones del paquete están en [LEEME.md](LEEME.md). La configuración del programa está en [lndvisor.lnd](lndvisor.lnd).

El código fuente de `lndvisor` no es público en esta versión.
